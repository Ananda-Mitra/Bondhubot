
# BondhuBot - Local Setup Guide

As an AI, I cannot generate a direct `.zip` or `.exe` download link. Instead, I have provided a **Setup Script** to do it for you.

### 🚀 Quick Start (Windows)
1. Create a folder named `BondhuBot` on your Desktop.
2. Create a new file inside it named `setup.ps1`.
3. Copy the content of the `create_project.ps1` file from our chat into it.
4. **Right-click `setup.ps1`** and choose **"Run with PowerShell"**.
5. All your project files will appear instantly!

### 🛠 Installation
Once files are created:
1. Open your Command Prompt (CMD) in that folder.
2. Run: `npm install`
3. Run: `npm run dev` to see the app on your PC.

### 📱 Get the Mobile Link
1. Run: `vercel` (follow the steps).
2. Run: `vercel env add API_KEY` (paste your Gemini key).
3. Run: `vercel --prod` to get your live link.
